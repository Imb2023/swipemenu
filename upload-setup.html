ONE-TIME OWNER SETUP

Connect your
media library.

Keep editing the menu in Google Sheets. Staff upload here and paste the links into the Sheet.

1. Create an account

Create your own account at Cloudinary. Review its current commercial terms and free-plan limits. Free storage, transformations, and video delivery have quotas; monitor usage.

2. Create a signed upload preset

In Cloudinary’s upload settings, create a Signed preset, not an unsigned/public preset. Allow only jpg, jpeg, png, webp, avif, mp4, and webm. Set a maximum file size of 10 MB (10,485,760 bytes) and disable overwrites. Use a separate media environment for this menu if possible.

Client checks reduce photos to 1200 px and limit clips to 15 seconds. The preset’s file restrictions must also be enforced by Cloudinary; browser checks alone are not an account limit.

3. Add Vercel environment variables

Open your project → Settings → Environment Variables. Add these to Production (and Preview only if you need staff uploads on previews):

  • CLOUDINARY_CLOUD_NAME — your cloud name
  • CLOUDINARY_API_KEY — the account’s API key
  • CLOUDINARY_API_SECRET — the account’s API secret
  • CLOUDINARY_UPLOAD_PRESET — the signed preset’s name
  • STAFF_UPLOAD_PASSWORD — a unique, randomly generated password, at least 24 characters

Enter secrets in Vercel, never in Google Sheets, GitHub, or chat. Share only the staff password with trusted staff. Rotate it when access changes.

4. Deploy and try one photo

Redeploy after adding the variables. Open /upload.html, upload a photo, copy its link, and paste it into the correct row’s image column. Staff content edits do not need another site deployment.

5. For an optional clip

Add a video column to the Sheet, upload a short MP4/WebM clip, paste its video link into that column and its preview link into image. Your Apps Script must return the new video column in its JSON. If it maps specific columns manually, add video to that mapping. Existing photos work without changing Apps Script.

The menu shows the photo immediately. A customer can choose to play the muted clip; other cards do not fetch videos.

Commercial hosting

Cloudinary’s free allowance is separate from hosting. Vercel’s Hobby plan is intended for personal, non-commercial use. A restaurant deployment needs a hosting plan that permits commercial use; check your plan before going live.

Account protection

The helper uses password-protected signed uploads. A small per-instance throttle is included; it is not a distributed abuse-prevention service. Use Vercel Firewall rate limits where available and Cloudinary’s format/size restrictions and usage alerts. Delete unused uploads in Cloudinary. Uploads are public and the helper does not edit or delete Sheet rows.
