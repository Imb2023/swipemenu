SwipeMenu restaurant setup guide
================================

The complete, current guide is README.md in this repository.
On GitHub, return to the repository's main page to read its formatted guide.

It includes:
- One-time setup for your own restaurant, spreadsheet, and hosting
- A ready-to-paste Google Apps Script and a CSV starter Sheet
- Daily staff instructions with no code changes
- Photo uploads without Cloudinary
- Optional clips and staff uploads
- Reasons for the design choices, troubleshooting, and technical checks

Captioned video: https://swipemenu.vercel.app/guide.html
Written transcript: docs/video-transcript.md

Use your own restaurant URL, data, and photos. Check application licensing and
commercial-hosting eligibility before deploying a copy.
