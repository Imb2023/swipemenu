# Demonstration media

The gallery at /demos.html uses five sample offers. Don Pedro uses the owner's
provided photo. Tacos, lime tequila soda, street corn, and churros were generated
for design demonstrations. They do not establish the restaurant's real portions,
ingredients, availability, or prices. Nothing is written to Google Sheets.

All demo photos are WebP, up to 800 x 1000, with 240 x 300 thumbnails. Larger
original generated PNGs remain outside the checkout in /workspace/generated_images.
Only WebP derivatives are used in the demo. Do not publish generated sample offers
as real menu items without checking the actual product and serving details.

The Focus design loads full photos as the guest scrolls. Quick list uses thumbnails.
Spotlight uses one full image plus thumbnails. Only the active design's images are
activated. No library, external font, video, provider account, or live API call is
needed to explore the gallery. The live menu remains a separate Sheet-driven page.
