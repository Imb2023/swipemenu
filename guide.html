Start with these files

  1. Create your own copy on GitHub. The code uses the MIT license; hosting and photo rights have separate terms.
  2. Download the Sheet template. Import it into a dedicated Google Sheet tab named Specials. Sample rows start hidden.
  3. Open the Apps Script template. Follow the written guide to connect and deploy it, then configure your own site.

After setup, staff only edit the Sheet

Change names, prices, descriptions, and photo links. Set available to FALSE when an offer sells out. The menu displays up to three available specials, sorted by order.

Allow about a minute plus Google’s response time for successful updates. If the app shows a saved menu, confirm availability with staff. Refresh the saved deployment snapshot for major menu changes.
